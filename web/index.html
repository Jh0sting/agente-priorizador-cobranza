# Cliente Tramo Días Saldo Prioridad Acción sugerida

Cómo se calcula la prioridad

Prioridad (0 a 100) = 35% urgencia + 35% recuperabilidad + 30% exposición. El cálculo es determinista y auditable: no lo hace la IA.

Urgencia

Sube a 100 cuando faltan 5 días o menos para que el crédito pase al siguiente tramo de mora.

Recuperabilidad

Pagos puntuales en 12 meses, promesas incumplidas, días de atraso y si tiene garantía.

Exposición

Saldo de capital en riesgo, en escala logarítmica respecto del mayor saldo de la cartera.

Si el cliente fue contactado hace menos de 3 días, la prioridad baja un 40% para no insistir de más. El agente de IA (Google ADK + Gemini) que conversa con el gestor y redacta mensajes personalizados se ejecuta localmente; ver el README.
